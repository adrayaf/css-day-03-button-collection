# Day 3 - Button Collection 🔴

Project ketiga dari challenge 30 Days CSS.

## 🔗 Live Demo
[Lihat di sini](https://adrayaf.github.io/css-day-03-button-collection)

## 🎯 Yang Dipelajari
- Base + modifier class pattern
- transition untuk hover effect
- transform: translateY & scale
- box-shadow untuk efek 3D & neon
- Pseudo-class :hover, :active, :disabled
- @keyframes untuk animasi spinner
- CSS Grid auto-fit & minmax
- border-radius untuk pill button

## 🛠️ Tech
HTML5 + CSS3
